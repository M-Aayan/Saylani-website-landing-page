# Saylani Website Login Page (HTML + CSS)

This repository contains a **static login page** designed for the **Saylani Welfare organization** using only **HTML** and **CSS**. The layout reflects a clean and professional design aimed at representing Saylani's values and user-friendly interface.

---

## 📌 About

The **Saylani Website Login Page** is a front-end static project created as part of a practice assignment. It serves as a visual prototype for a welfare-based organization’s login portal, focusing on:

- **Simplicity**
- **Clarity**
- **Visual appeal**

> ⚠️ Note: This is a **static layout only** – no backend or form validation functionality is included.

---

## 🧠 Key Features

- Clean and structured **login form**
- Modern layout aligned with Saylani’s brand style
- Input fields for **email/username** and **password**
- "Login" button and optional links like "Forgot Password?"

---

## 🛠 Technologies Used

| Technology | Description |
|------------|-------------|
| **HTML5**  | Structure and layout of the login page |
| **CSS3**   | Styling, spacing, and visual design |
| *(No JavaScript)* | *(No interactivity or backend connection)* |
